# motem: `.mtm` as a standalone file

`tove` is now `motem` and map keys may be quoted strings, so a manifest like
`fs-catasto`'s can be keyed by destination path. What is missing is the file:
nothing in the toolchain knows `.mtm` yet.

Workspace: `.agents/workspaces/tove-to-motem` (reuse or replace it).

## Decided

- The extension is `.mtm` (motem is tomet's dual: `tmt` / `mtm`).
- A standalone file is a top-level map written as bare `key: value` lines, no
  enclosing braces and no `@kind` / `@config` wrapper (`motem::print_value`
  already writes that shape; `motem::from_str` reads it).
- `fs-catasto` reads `catasto.mtm` and writes `catasto.lock` in motem, keyed by
  destination path:

  ```
  "tmtroot/schema/rust.vocabulary.tmt": "../vocabularies/rust.vocabulary.tmt"
  "tmtroot/schema/writ.vocabulary.tmt": { git: "...", rev: main, path: "..." }
  ```

## Done: stage A (CLI)

`tomet check` and `tomet format` take a `.mtm` beside a `.tmt`, in a directory
sweep too, under the same ignore rules. A `.mtm` is data, not a vault document:
no vocabulary, no index, no links (`tomet_indexer::collect_tm_files` still
leaves it out; `collect_tm_and_mtm_files` is the one that reaches it).

- `check`: `motem_syntax::parse_file` -- parses, and every entry has a key.
- `format`: whitespace only (`tomet_formatter::format_data_source`); a quoted
  string is copied exactly, a file that does not parse is left alone.

Still open: stage B LSP (diagnostics, formatting, the `**/*.tmt` watcher in
`apps/lsp/src/main.rs`), C `tree-sitter-motem` (a second hand-maintained
grammar, layer 0, with its own corpus in `tomet-tests`), D editors (VS Code,
Zed, Helix, Neovim: register `.mtm`, highlight with C; VS Code uses TextMate).

## To decide

- What `.mtm` means to `tomet`: `tomet roundtrip`, `tomet check`/`format` over
  `.mtm`, the workspace indexer (does an `.mtm` belong to a vault?), LSP, the
  editors (VS Code, Zed, Helix, Neovim), and `tree-sitter` (a second grammar, or
  the value grammar reused).
- Comments: motem has `//` only (`/* */` belongs to tomet documents). `to_string`
  cannot write one, so a tool that wants a header (`// Generated by ... Do not
  edit`) writes it ahead of the body itself; `parse_file` and `format` keep it.
- `tmtroot/shelf.toml` is still TOML; same question as catasto's manifest.

## Not started

- `tandr` (`Cargo.toml`, `tandr-core`) names `tove` directly; follow once this
  lands. Other repos only carry it in `Cargo.lock` and pick it up on a rev bump.
- `tree-sitter-tomet` cannot parse `@x(a, c: 2)` or `@x(a, b)`: a positional
  argument followed by more. Predates the rename; not needed for `.mtm`.
