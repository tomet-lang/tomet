# Task: Web Real-Time Playground for TypedMark

## Goal

Create a rich, real-time Web Playground for TypedMark so users can instantly type `.tm` markup and inspect HTML preview, AST data structure, and CommonMark export directly in their browser.

## Steps

- [ ] **Step 1**: Add `/api/parse` endpoint and Web Playground UI to `apps/typedmark` CLI (under `typedmark playground` or `typedmark serve`).
- [ ] **Step 2**: Design and craft a stunning modern Web UI (`index.html` / embedded assets with dark theme, Split View, live AST inspector, and sample presets).
- [ ] **Step 3**: Test server execution and `/api/parse` response payload.
- [ ] **Step 4**: Verify whole workspace with `cargo test --workspace`.
- [ ] **Step 5**: Clean up task file upon completion and provide instructions for the user.
